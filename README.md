# 🏕️ Wild Town — เกมสร้างเมืองเอาตัวรอด เล่นหลายคน (3D บนเว็บ)

ช่วยกันล่าหมูป่า ตัดไม้ แปรรูปของ ขายให้ชาวบ้านที่มาต่อคิว เอาเงินไปสร้างเมือง แล้วป้องกันศาลากลางจากฝูงมอนสเตอร์ยามค่ำคืนให้รอดจนครบกำหนดวัน

## วิธีรัน

ต้องมี [Node.js](https://nodejs.org) 18 ขึ้นไป (ไม่ต้อง `npm install` เพราะไม่มี dependency)

```bash
node server.js
```

เปิดเบราว์เซอร์ที่ `http://localhost:8765`
- **เพื่อนในวง Wi-Fi/LAN เดียวกัน**: เปิดลิงก์ `http://<IP เครื่องคุณ>:8765` ที่เซิร์ฟเวอร์พิมพ์ออกมาตอนเริ่ม (ถ้าเข้าไม่ได้ ให้อนุญาต Node ใน Windows Firewall)
- **เล่นผ่านอินเทอร์เน็ต**: ใช้ tunnel เช่น `cloudflared tunnel --url http://localhost:8765` หรือ `ngrok http 8765` แล้วส่งลิงก์ให้เพื่อน
- เปลี่ยนพอร์ต: `PORT=9000 node server.js` (PowerShell: `$env:PORT=9000; node server.js`)

### วงจรเศรษฐกิจ
- 🐗 หมูป่า → 🥩 เนื้อดิบ → **เตาย่าง** → 🍖 สเต็ก → **ร้านสเต็ก** → ชาวบ้านซื้อ ($8/ชิ้น) → 💰
- 🌲 ต้นไม้ → 🪵 ไม้ซุง → **โรงเลื่อย** → 🪚 ไม้แผ่น → ใช้สร้างกำแพง/หอธนู หรือขายที่ **ร้านขายไม้** ($4/ชิ้น)
- ⛏️ ก้อนหินในป่า → 🪨 หิน → อัปเกรดกำแพง/หอธนูเป็นหิน, สร้างปืนใหญ่
- 👑 ลูกค้า VIP จ่ายราคา x2
- เงินเป็นของทั้งทีม (ใช้ร่วมกัน) · โรงเลื่อยมีให้ตั้งแต่เริ่ม ไม้ที่ตัดมาใช้ได้ทันที

### สิ่งที่สร้างได้
- โรงเลื่อย, ร้านขายไม้
- กำแพง 8 ด้าน (ไม้ → อัปเกรดเป็นหิน), หอธนู 4 หอ (ไม้ → หิน ยิงแรงและไวขึ้น), ปืนใหญ่ 4 จุด (ระเบิดวงกว้าง)
- จ้างคนงาน: คนตัดไม้, นายพราน, คนส่งของ, แคชเชียร์ (จ้างเพิ่มได้หลายคน)
- อัปเกรดทีม: กระเป๋า, ความเร็ว, ธนู, ขวาน, เตาไฟ, ใบเลื่อย

### กลางวัน / กลางคืน
- เลือกความยาวเกมได้ 3 / 5 / 7 วัน (วันแรก 2 นาที, วันต่อไป 1.5 นาที, กลางคืน 1 นาที)
- กลางคืน **ประตูมิติ** เปิดที่ขอบป่า (เห็นบนแผนที่เล็ก) มอนสเตอร์บุก: ก็อบลิน → หมาป่าเงา (คืน 2+) → ยักษ์ (คืน 3+) → **ราชาปีศาจ** คืนสุดท้าย
- ความยากเพิ่มตามจำนวนผู้เล่น · รุ่งเช้ามอนสเตอร์ถูกแดดเผา และสิ่งก่อสร้างซ่อมตัวเอง
- **ชนะ** เมื่อศาลากลางรอดจนหมดเวลา · **แพ้** เมื่อศาลากลางพัง
- ตายแล้วฟื้นที่ศาลากลางใน 6 วินาที (ของในกระเป๋าหาย)
- **เน็ตหลุด / รีเฟรชหน้า**: เกมต่อกลับให้อัตโนมัติ ได้ตัวละครเดิม ของในกระเป๋าและสถิติยังอยู่ ถ้ากลับมาภายใน 60 วินาที · ถ้าทุกคนหลุดหมด เกมจะหยุดรอ · เปิดตัวละครเดียวกันในแท็บ/เครื่องอื่น แท็บเก่าจะถูกตัดออก
- ปุ่มไอคอนใต้แผนที่เล็ก: 🎵 เพลงประกอบ (กด **M**), 🔔 เสียงเอฟเฟกต์, ✨/⚡ กราฟิกสูง / โหมดลื่น (ปิด bloom, ลดของตกแต่ง) สำหรับเครื่องที่ไม่แรง

## โครงสร้างไฟล์

```
server.js          HTTP + WebSocket (เขียนเอง ไม่ใช้ไลบรารี) + ตรรกะเกมทั้งหมด (server-authoritative, 20 tick/s)
public/index.html  UI / HUD
public/game.js     ตัวเกม 3D (Three.js จาก CDN) — เรนเดอร์, การเดิน, เอฟเฟกต์, เสียง
public/shared.js   ค่าคอนฟิกที่ใช้ร่วมกัน (แปลงก่อสร้าง, ราคา, มอนสเตอร์, สูตรอัปเกรด)
```

ปรับสมดุลเกมได้ที่ `public/shared.js` (ราคา, ค่าก่อสร้าง, ความยาววัน) · ทดสอบแบบเร่งเวลา: `SPEED=8 node server.js`
